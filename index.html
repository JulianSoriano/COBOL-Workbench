Quick reference

Fixed-format columns

1–6Seq
7*
8A
12–72Area B · statements
73+Ignored

Division, section and paragraph names start in Area A (column 8). Statements go in Area B (column 12 onward). Switch to Free format in the editor bar to type anywhere; free-format comments start with *>.

PIC symbols

Xany character
Aletter or space
9digit
Vimplied decimal point (not printed)
Snumber can be negative
(n)repeat: X(5) is XXXXX
Z , .zero suppression, comma, printed decimal
$ * - + CR DBcurrency, cheque stars, signs

Statements

DISPLAYprint values; add NO ADVANCING to stay on the line
ACCEPTread typed input, or FROM DATE / TIME
MOVEcopy a value, fitted to the receiving PIC
ADD SUBTRACT MULTIPLY DIVIDEwith GIVING, ROUNDED, REMAINDER, ON SIZE ERROR
COMPUTEformulas with + - * / **
IF / EVALUATEdecisions; close with END-IF / END-EVALUATE
PERFORMparagraphs, TIMES, UNTIL, VARYING, inline with END-PERFORM
SETSET name TO TRUE for 88 levels; UP BY / DOWN BY
STRING UNSTRINGjoin and split text
INSPECTTALLYING, REPLACING, CONVERTING
INITIALIZEreset to spaces and zeros
GO TO / EXITjump to a paragraph; EXIT PARAGRAPH, EXIT PERFORM
STOP RUNend the program (GOBACK also works)

Not supported here

This workbench runs a teaching subset of COBOL in your browser. Files (FD, OPEN, READ, WRITE), REDEFINES, COPY, CALL, SORT, SEARCH and tables inside tables aren't available. Saved .cbl files are standard source, so they also compile with GnuCOBOL: cobc -x HELLO.cbl.
